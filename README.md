# CollierIT

**Network & Streaming Infrastructure Engineering | OTT / Broadcast Systems | Technical Operations**

CollierIT is the professional portfolio and consulting site of **Andrew Collier**, an independent technology consultant and engineer with 11+ years of hands-on experience across network infrastructure, systems, hosting, media delivery, and application platforms.

Since 2020, my primary long-term work has included end-to-end technical ownership of infrastructure supporting a production U.S. OTT television environment—from multicast networking and servers through transcoding, DRM, CDN delivery, EPG data, and consumer playback.

## Core areas

- **Network engineering:** Layer 2/3, VLANs, routing, switching, firewalls, QoS, UDP multicast, IGMP, DNS/DHCP, high availability, 25/100GbE
- **Streaming & OTT:** MPEG-TS, SRT, RTP, HLS, MPEG-DASH, Flussonic, H.264/NVENC, captions, EPG/Gracenote
- **Systems & infrastructure:** Windows Server, Ubuntu Linux, Hyper-V, NVIDIA GPU acceleration, Docker, monitoring, lifecycle management
- **Content delivery & security:** AWS CloudFront/CDN, TLS, CORS, Widevine DRM, BuyDRM/KeyOS
- **Applications & operations:** Android/Google TV/Fire TV, Media3/ExoPlayer, web administration tools, APIs, Git/GitHub, QA and incident response
- **AI-assisted engineering:** coding agents and generative AI used to accelerate scripting, investigation, prototyping, testing, and documentation with hands-on validation before production use

## Selected scale

- 6+ years supporting production OTT operations
- Approximately 90 live multicast channel inputs
